# Week 1 – Software Delivery Foundations

> Part of the Thynqit Labs – Foundational Engineering Bootcamp

---

## 📌 Module Overview

This module focuses on how modern software is planned, built, reviewed, and delivered.

Before writing scalable code, engineers must understand:

- How software teams operate
- How work is structured and tracked
- How collaboration happens
- How version control enables safe development

This week builds the foundation for engineering discipline and collaborative development.

---

## 🎯 Learning Outcomes

By the end of this week, learners should be able to:

- Understand the Software Development Lifecycle (SDLC)
- Explain Agile principles and Scrum workflow
- Write structured user stories
- Use issue tracking systems effectively
- Use Git for collaborative development
- Understand code review and branching strategies

## 🔗 How This Module Connects

This module lays the groundwork for everything that follows.

Without understanding:

- How software is delivered,
- How teams collaborate,
- How changes are tracked,

even technically strong engineers struggle in real-world projects.

This week prepares learners for:

- API design discussions
- Backend development workflows
- Production deployments
- Structured code contributions

---

## 🧠 Engineering Perspective

Mature engineers understand that:

- Writing code is only part of the job.
- Collaboration and process discipline prevent system failures.
- Poor version control practices cause production issues.
- Lack of structured workflow leads to chaos.

Strong engineering starts with strong process understanding.
