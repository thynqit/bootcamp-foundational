# Week 1 – Security & Software Delivery Foundations

> Part of the Thynqit Labs – Foundational Engineering Bootcamp

---

## 📘 Overview

Modern software engineers are responsible not only for writing code but also for understanding how software systems are planned, built, reviewed, delivered, and secured.

This module introduces the **foundational principles of professional software development**. It focuses on the practices that enable engineering teams to build reliable, maintainable, and secure software systems.

Before writing scalable code, engineers must understand:

- Cybersecurity awareness
- How software teams operate
- How work is structured and tracked
- How collaboration happens
- How version control enables safe development

These concepts form the **operational backbone of modern engineering teams**.

This week builds the foundation for engineering discipline and collaborative development.

---

## 🎯 Learning Objectives

By the end of this week, learners should be able to:

- Understand the importance of cybersecurity awareness for engineers
- Understand the Software Development Lifecycle (SDLC)
- Explain Agile principles and Scrum workflow
- Write structured user stories
- Use issue tracking systems effectively
- Use Git for basic version control workflows

## 🧠 Engineering Perspective

Experienced engineers view these topics as **non-negotiable fundamentals**.

- Cybersecurity awareness prevents human error from becoming the primary gateway for enterprise-wide crises.
- Understanding SDLC and Agile enables teams to collaborate efficiently.
- Structured requirements and issue tracking ensure that teams build the right features.
- Version control provides the safety net that allows teams to evolve systems without losing history or stability.

Many early-career engineers underestimate these foundations, but experienced engineers know that **strong engineering process is what enables scalable software systems**.
