# Resources – Day 5: Git Basics (CLI First Approach)

> Part of the Thynqit Labs – Foundational Engineering Bootcamp

---

## 📌 Overview

Curated learning resources to understand Git fundamentals using the command line.

These resources help learners understand:

- how Git tracks changes
- how distributed version control works
- how engineers collaborate safely using Git workflows

Focus on learning Git through **CLI commands rather than graphical tools**.

---

## 📖 Official Documentation & Authoritative Sources

These are the most reliable and primary sources for learning Git.

- Git Official Documentation  
  https://git-scm.com/docs

- Pro Git Book (Free & Official)  
  https://git-scm.com/book/en/v2

- Git Reference (Command List)  
  https://git-scm.com/docs/git

These sources explain Git from first principles and are maintained by the Git community.

## 📌 Suggested Learning Flow

1. Read basic Git concepts from the **Pro Git Book**.
2. Practice commands locally via **CLI**.
3. Watch one structured tutorial demonstrating Git in terminal.
4. Use **Git official documentation** as reference while practicing.
5. Avoid relying on GUI tools until CLI concepts are clear.

> Mastering Git through CLI builds deeper understanding than using graphical tools alone.
