# Security Policy

## Supported Content

This repository is actively maintained and updated by Thynqit Labs.

All current content in the main branch is considered supported.

---

## Reporting a Vulnerability

If you discover a security-related issue in this repository, such as:

- Insecure coding practices in examples
- Misleading or incorrect security guidance
- Vulnerabilities in shared resources or references

Please report it responsibly.

You can:

- Open an issue with clear details, or
- Contact the maintainers directly (if sensitive)

---

## Responsible Disclosure

We request that you:

- Do not publicly disclose vulnerabilities without giving us time to review and respond
- Provide sufficient information to reproduce the issue
- Allow reasonable time for fixes or updates

---

## Scope

This repository is intended for educational purposes.

While we aim to follow best practices, all examples and content should be reviewed and adapted before use in production systems.

---

## Our Commitment

We take security seriously and will:

- Review reported issues promptly
- Update or correct content where needed
- Continuously improve the quality and accuracy of the material

---

## Final Note

Security is a shared responsibility.

This repository aims to promote a security-first mindset in engineering — we welcome contributions that improve it.
