# 🧠 Key Takeaway

Modern internet-scale systems achieve scalability using combinations of:

- horizontal scaling
- caching
- replication
- partitioning
- asynchronous communication
- distributed infrastructure

Scalability always introduces trade-offs between:

- complexity
- consistency
- reliability
- operational overhead

Strong engineers understand these trade-offs before scaling systems aggressively.
