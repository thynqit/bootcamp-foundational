# Resources – Day 16: Cloud Fundamentals

> Part of the Thynqit Labs – Foundational Engineering Bootcamp

---

## 📌 Overview

These resources help you understand:

- what cloud computing is
- how modern systems run in the cloud
- core infrastructure components (compute, storage, networking)
- system architecture concepts like load balancing, CDN, API gateway
- how major cloud providers structure their services

This section focuses on **conceptual clarity**, not platform-specific tutorials.

---

# ☁️ 1. What is Cloud Computing?

---

## 📖 Learn

- https://www.cloudflare.com/learning/cloud/what-is-cloud-computing/  
- https://azure.microsoft.com/en-in/resources/cloud-computing-dictionary/what-is-cloud-computing/  

---

## 🧠 Key Understanding

- cloud provides computing resources over the internet  
- eliminates need for physical infrastructure  
- enables scalability and global access

# 📌 Suggested Learning Flow

1. Start with cloud fundamentals.
2. Understand service models (IaaS, PaaS, SaaS).
3. Learn core infrastructure components.
4. Explore load balancing and CDN.
5. Understand IAM and security.
6. Learn scaling and high availability.
7. Review cloud providers for awareness.

---

## ⚠️ Key Takeaways

- cloud is infrastructure, not magic  
- architecture matters more than tools  
- scaling and availability are core design concerns  
- security (IAM, firewall) is critical  
- all cloud providers follow similar principles
