# Week 4 – Cloud & Infrastructure

> Part of the Thynqit Labs – Foundational Engineering Bootcamp

---

## 📘 Overview

Modern software systems are not just built — they are **deployed, scaled, monitored, and maintained in the cloud**.

This module introduces the foundational concepts required to understand:

- how applications run in cloud environments
- how software is built and deployed using CI/CD pipelines
- how systems are monitored and debugged in production
- how networking enables communication between systems
- how engineers interact with infrastructure using Linux CLI

By the end of this week, learners will transition from writing code to understanding **how that code runs in real-world systems**.

---

## 🎯 Learning Objectives

By the end of this module, learners should be able to:

- understand core cloud computing concepts (IaaS, PaaS, SaaS)
- explain how applications are deployed and managed in cloud environments
- understand CI/CD pipelines and DevOps practices
- interpret logs and monitor system health
- understand networking fundamentals (DNS, IP, ports, routing)
- use basic Linux CLI commands to interact with systems
- understand how infrastructure supports scalable applications

## 🧠 Engineering Perspective

In real-world systems:

- code runs on servers, not laptops
- deployments must be automated and reliable
- failures must be observable and debuggable
- systems must scale based on demand

Engineers must understand:

- where their code runs
- how it is deployed
- how it is monitored
- how it communicates across networks

This is the foundation of **production-grade engineering**.

---

## 📚 Suggested Approach

Recommended progression:

1. Understand how cloud platforms host applications.
2. Learn how code moves from development to production (CI/CD).
3. Understand how systems are monitored and debugged.
4. Learn how networking enables communication between services.
5. Practice Linux CLI commands to interact with servers.

Focus on **understanding systems**, not just tools.
