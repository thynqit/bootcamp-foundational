# Resources – Day 20: Linux CLI for Engineers

> Part of the Thynqit Labs – Foundational Engineering Bootcamp

---

## 📌 Overview

These resources help you understand how to work with Linux systems using the Command Line Interface (CLI).

They cover:

- Linux fundamentals
- essential CLI commands
- file system navigation
- process and system monitoring
- shell scripting basics
- real-world command usage

This module is highly practical — learners are encouraged to **try commands on their own system or a cloud VM**.

---

## 📖 Official Documentation & Authoritative Sources

### Linux Command Documentation (GNU Core Utilities)

https://www.gnu.org/software/coreutils/manual/coreutils.html

Covers:

- file operations (`ls`, `cp`, `mv`, `rm`)
- text processing
- system utilities

### Linux Manual Pages (man pages)

https://man7.org/linux/man-pages/

Covers:

- detailed documentation for Linux commands
- system calls and utilities
- real-world command usage

Example:

```
man ls
man grep
man chmod
```

### Bash Official Documentation

- shell behavior
- scripting fundamentals
- variables and execution model

### Option 3 – Cloud VM (Advanced Practice)

Use free tier:

- AWS EC2
- Azure VM

- SSH into server
- run CLI commands
- simulate production debugging

---

## 📌 Suggested Learning Flow

1. Start with DigitalOcean or Ubuntu tutorials for basics.
2. Practice commands locally or using browser terminal.
3. Use `man` pages to explore commands deeply.
4. Watch one structured video tutorial.
5. Write small shell scripts to automate tasks.
6. Try commands on a cloud VM for real-world experience.

---

## 🧠 Key Takeaway

Reading about CLI is not enough.

You must:

- execute commands
- break things
- debug errors
- repeat until comfortable

CLI proficiency comes from **practice, not theory**.
