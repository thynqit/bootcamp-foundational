# Thynqit Bootcamp – Foundational

Welcome to the foundational onboarding program at Thynqit Labs.

This repository contains structured learning material to help engineers understand our culture, engineering principles, and development workflows.

---

## 🎯 Objective

- Understand Thynqit engineering philosophy
- Learn our development lifecycle
- Get familiar with coding standards
- Understand branching and release strategy
- Learn AI-assisted development workflows

---

## 📚 Modules

1. Engineering Culture & Expectations
2. Code Quality Standards
3. Git Workflow & Branching Strategy
4. Architecture Principles
5. DevOps & CI/CD Basics
6. AI in Engineering at Thynqit

---

## 🛠 Expected Outcome

After completing this bootcamp, engineers should be able to:

- Contribute to accelerators
- Follow engineering governance
- Raise high-quality PRs
- Work within structured sprint cycles
