# Resources – Day 9: Data Formats

> Part of the Thynqit Labs – Foundational Engineering Bootcamp

---

## 📌 Overview

These resources help you understand how structured data is represented and exchanged between systems.

They cover:

- JSON structure and syntax
- XML structure and markup
- differences between JSON and XML
- CSV for tabular data
- tools to visualize and validate data formats

Understanding these formats helps engineers design APIs, integrate systems, and debug data exchanges.

---

## 📖 Official Documentation & Authoritative Sources

These sources provide reliable documentation for commonly used data formats.

### JSON Specification (Official Standard)

https://www.rfc-editor.org/rfc/rfc8259

Defines the official specification for JSON data format.

Covers:

- syntax rules
- objects and arrays
- encoding standards

---

### JSON.org – JSON Syntax Overview

https://www.json.org/json-en.html

Explains:

- JSON syntax rules
- objects and arrays
- how JSON structures data

---

### W3C – XML Introduction

https://www.w3schools.com/xml/xml_whatis.asp

- XML structure
- tags and elements
- nested data representation

## 📌 Suggested Learning Flow

1. Start with the MDN JSON guide to understand the structure.
2. Review the official JSON specification to understand syntax rules.
3. Learn how XML structures data using nested tags.
4. Compare JSON and XML to understand their differences.
5. Use JSON formatter tools to explore real API responses.

> Most modern APIs use JSON, but understanding XML and CSV helps engineers work with legacy systems and data pipelines.
