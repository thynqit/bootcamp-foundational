# Resources – Day 6: Git Branching & Code Review

> Part of the Thynqit Labs – Foundational Engineering Bootcamp

---

## 📌 Overview

These resources explain how engineering teams collaborate using Git through branching workflows and code reviews.

They focus on:

- Git branching strategies
- pull request workflows
- collaborative development practices
- code review discipline

Understanding these concepts helps engineers work effectively in shared codebases.

---

## 📖 Official Documentation & Authoritative Sources

Primary sources explaining Git workflows and collaboration.

- Git Documentation – Branching and Merging  
  https://git-scm.com/docs/git-branch

- GitHub Docs – About Pull Requests  
  https://docs.github.com/en/pull-requests

- GitHub Docs – About Code Review  
  https://docs.github.com/en/pull-requests/collaborating-with-pull-requests

These documents describe how collaborative development works in modern repositories.

## 📌 Suggested Learning Flow

1. Read Atlassian's Git branching tutorial.
2. Understand GitHub's pull request workflow.
3. Watch one video explaining branching strategies.
4. Practice creating branches and merging them locally.
5. Open a pull request in a test repository.

> Collaborative Git workflows are essential for safe and scalable software development.
