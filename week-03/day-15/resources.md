# Resources – Day 15: Testing Fundamentals

> Part of the Thynqit Labs – Foundational Engineering Bootcamp

---

## 📌 Overview

These resources focus on understanding:

- what different types of testing are
- why they are important
- how they are applied in real-world systems

This section intentionally focuses on **conceptual clarity** rather than tool-specific tutorials.

Tools are referenced only to provide awareness of industry usage.

---

# 🧪 1. Unit Testing

---

## 📖 Learn

- https://martinfowler.com/bliki/UnitTest.html  
- https://www.atlassian.com/continuous-delivery/software-testing/types-of-software-testing  

---

## 📖 Learn

# 🧪 3. Non-Functional Testing

---

## 📖 Learn

- https://www.guru99.com/non-functional-testing.html  

---

## 🧠 Key Understanding

- tests system qualities, not features

- performance
- scalability

- usability

---

# 🧪 4. Black Box / White Box / Grey Box Testing

---

## 📖 Learn

- https://www.geeksforgeeks.org/software-testing/software-engineering-white-box-testing/  
- https://www.geeksforgeeks.org/software-testing/software-engineering-black-box-testing/  
- https://www.geeksforgeeks.org/software-testing/gray-box-testing-software-testing/  

---

## 🧠 Key Understanding

- Black Box → no knowledge of internal logic
- White Box → full access to code
- Grey Box → partial knowledge

These define **testing perspective**, not testing type.

# 📌 Suggested Learning Flow

1. Start with Unit and Functional Testing.
2. Understand Non-Functional testing types.
3. Learn testing perspectives (Black/White/Grey box).
4. Explore API and Regression testing.
5. Understand performance and security testing.
6. Learn how automation fits into the testing lifecycle.

---

## ⚠️ Key Takeaways

- Testing is not limited to QA — developers must test
- Different testing types serve different purposes
- Regression testing is critical in evolving systems
- API testing is central to modern backend systems
- Non-functional testing is often ignored but crucial
