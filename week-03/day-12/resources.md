# Resources – Day 12: Database Design Fundamentals

> Part of the Thynqit Labs – Foundational Engineering Bootcamp

---

## 📌 Overview

These resources help you understand how data is stored, structured, and managed in backend systems.

They cover:

- relational database fundamentals
- SQL concepts and schema design
- NoSQL database types and data modeling
- real-world database usage patterns

Understanding databases is essential for designing scalable and reliable backend systems.

---

## 📖 Official Documentation & Authoritative Sources

These are reliable and widely used references for database concepts.

---

### Database Concepts

https://aws.amazon.com/what-is/database/

Covers:

- types of databases
- relational vs non-relational systems
- real-world use cases
- cloud database services

Provides a high-level industry perspective.

---

### PostgreSQL Documentation

https://www.postgresql.org/docs/

Covers:

- relational database concepts
- tables, keys, and constraints
- indexing and performance
- advanced database features

PostgreSQL is one of the most widely used relational databases in production systems.

---

### MongoDB Documentation

https://www.mongodb.com/docs/

Explains:

- document-based database structure
- JSON data modeling
- schema flexibility
- indexing and performance

MongoDB is one of the most popular NoSQL databases.

## 🎓 Structured Learning Material

These resources explain database design concepts in a practical and structured way.

---

### SQLBolt – Learn SQL (Interactive)

https://sqlbolt.com/

Provides:

- interactive SQL lessons
- query examples (SELECT, JOIN, etc.)
- hands-on exercises

Useful for beginners to understand SQL practically.

---

### MongoDB Data Modeling Guide

https://www.mongodb.com/docs/manual/core/data-modeling-introduction/

Explains:

- schema design in NoSQL
- embedding vs referencing
- denormalization strategies
- performance considerations

Helps understand how NoSQL design differs from relational systems.

---

### MySQL Tutorial (Official)

https://dev.mysql.com/doc/refman/8.0/en/tutorial.html

Provides:

- step-by-step introduction to MySQL
- creating tables and inserting data
- basic querying
- simple relational concepts

Useful for getting started with MySQL practically.

## 🛠 Database Playgrounds (Hands-On Practice)

These tools allow you to practice SQL and NoSQL queries directly in your browser without installing anything.

---

### SQL Playground – DB Fiddle

https://www.db-fiddle.com/

Features:

- supports multiple databases (MySQL, PostgreSQL, SQLite)
- write and execute SQL queries
- test schema designs

Useful for experimenting with real SQL queries.

---

### SQL Playground – SQLite Online

https://sqliteonline.com/

Allows you to:

- create tables
- insert data
- run queries instantly

Simple and lightweight for quick practice.

---

### NoSQL Playground – MongoDB Playground

https://mongoplayground.net/

Allows you to:

- write MongoDB queries
- test aggregation pipelines
- experiment with JSON documents

Best tool for practicing document-based NoSQL queries.

## 📌 Suggested Learning Flow

1. Start with AWS database overview to understand types.
2. Study relational concepts using PostgreSQL documentation.
3. Practice SQL and NoSQL basics using playgrounds
4. Learn NoSQL modeling using MongoDB documentation.
5. Compare SQL vs NoSQL use cases.
6. Watch videos to reinforce concepts visually.

> Strong database design is the foundation of reliable backend systems.
